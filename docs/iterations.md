# 三次迭代计划

## 第一次：v0.1 基础闭环（本次交付）

控制台客户端、公共协议、注册登录、目录管理、SQLite、分块上传下载、SHA-256 校验、秒传、多客户端线程和基础测试。

## 第二次：v0.2 可用桌面版

- Qt 6 Widgets 登录页、主窗口、`QTableView` 云端模型和传输面板；
- `QtClientBridge` 信号槽适配，网络与哈希不阻塞 GUI；
- 控制连接 + 每任务独立连接及 `TRANSFER_BIND`；
- 后台上传/下载、并发上限、取消、失败重试；
- PBKDF2-HMAC-SHA-256、会话超时、心跳、优雅停机；
- 配置文件、日志、仓储/传输集成测试和 Windows 打包。

第二版不应同时做 IOCP、断点续传和创新转换，以免破坏已跑通主链路。

## 第三次：v1.0 创新与答辩版

- 已有 MarkItDown 同步外部进程适配支持 DOCX/PDF → Markdown，后续扩展为可注册转换器接口；
- 不宣称任意格式双向互转，扫描 PDF/OCR 仍作为可选增强；
- FFmpeg 视频代表封面和有限张时间轴拼图；
- 转换任务状态、缓存、进度、失败诊断及 UI 预览；
- 可选目录变更推送、断点续传和演示数据；
- 压测、故障测试、答辩脚本与最终说明书。

IOCP、P2P、分布式存储、流式视频播放和相似内容“秒传”不列为三版内硬指标。
